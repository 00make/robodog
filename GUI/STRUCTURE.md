# GUI文件夹结构说明

```
GUI/
├── unified_control.py      # 主程序文件 - 集成所有控制功能的GUI应用
├── README.md              # 详细使用说明文档
├── INSTALL.md             # 快速安装指南
├── requirements.txt       # Python依赖列表
├── config_example.ini     # 配置文件示例
├── start.bat             # Windows启动脚本
└── start.sh              # Linux/macOS启动脚本
```

## 📁 文件说明

### 🎮 unified_control.py
**主程序文件**
- 集成键盘控制、手柄控制、GUI按钮控制
- 统一的图形界面
- 实时参数调节
- 状态监控和日志记录
- 多线程控制架构

**主要特性：**
- 三种控制模式无缝切换
- 实时调节速度、身高等参数  
- 支持组合操作和即按即走
- 完善的错误处理和安全机制
- 直观的状态显示和连接指示

### 📖 README.md
**详细使用说明**
- 完整的功能介绍
- 逐个区域的界面说明
- 操作工作流程
- 故障排除指南
- 技术参数和高级配置

### 🚀 INSTALL.md
**快速安装指南**
- 一键启动说明
- 依赖安装步骤
- 常见问题解答
- 快速上手流程

### ⚙️ config_example.ini
**配置文件模板**
- 所有可配置参数的说明
- 默认值和取值范围
- 自定义按键映射
- 性能和安全设置

### 🔧 启动脚本
**start.bat (Windows)**
- 自动检查Python环境
- 验证必要库安装
- 一键启动程序

**start.sh (Linux/macOS)**
- 跨平台启动支持
- 环境依赖检查
- 权限自动设置

### 📦 requirements.txt
**依赖管理**
- 精确的版本要求
- 核心和可选依赖说明
- 安装指导注释

## 🔄 版本兼容性

### Python版本
- **最低要求：** Python 3.7
- **推荐版本：** Python 3.8+
- **测试版本：** Python 3.9, 3.10, 3.11

### 操作系统
- **Windows：** Windows 10/11
- **macOS：** macOS 10.14+
- **Linux：** Ubuntu 18.04+, CentOS 7+

### 硬件要求
- **内存：** 最低512MB，推荐1GB+
- **CPU：** 双核1GHz+
- **网络：** WiFi或有线网络
- **设备：** 键盘、鼠标、手柄（可选）
