# 机器狗统一控制中心 GUI 使用说明

## 📋 概述

机器狗统一控制中心是一个集成了键盘控制、手柄控制和GUI按钮控制的统一图形界面应用程序。通过这个应用程序，您可以使用多种方式来控制机器狗，并实时监控机器狗的状态。

## 🚀 快速开始

### 安装依赖

确保已安装所需的Python包：

```bash
pip install -r ../requirements.txt
```

### 运行程序

```bash
python unified_control.py
```

## 🎮 界面功能详解

### 1. 🔗 机器狗连接区域

**功能：** 管理与机器狗的网络连接

**组件：**
- **IP地址输入框：** 输入机器狗的IP地址（默认：192.168.118.29）
- **连接按钮：** 点击连接/断开机器狗
- **连接状态标签：** 显示当前连接状态
- **连接指示器：** 绿色表示已连接，红色表示未连接

**使用步骤：**
1. 确保机器狗已开机并连接到同一网络
2. 在IP地址输入框中输入正确的机器狗IP地址
3. 点击"连接"按钮
4. 观察连接状态指示器变为绿色，状态标签显示"已连接"

### 2. 🎮 控制模式区域

**功能：** 选择和管理不同的控制方式

**三种控制模式：**

#### 键盘控制模式
- **特点：** 即按即走，松开即停
- **适用场景：** 精确控制，适合在电脑前操作
- **状态指示：** 显示键盘监听状态

#### 手柄控制模式  
- **特点：** 模拟摇杆控制，支持无级调速
- **适用场景：** 游戏式操作体验，适合远距离控制
- **状态指示：** 显示手柄连接状态和名称

#### GUI按钮控制模式
- **特点：** 鼠标点击操作，简单直观
- **适用场景：** 触屏设备，简单操作

**功能按钮：**
- **刷新手柄：** 重新检测游戏手柄连接
- **启动/停止键盘监听：** 控制全局键盘监听

### 3. ⚙️ 控制参数区域

**功能：** 实时调节机器狗的运动参数

#### 速度控制
- **范围：** 6档速度等级（0.2 - 2.0 m/s）
- **默认：** 第3档（0.8 m/s）
- **实时调节：** 拖动滑块即时生效

#### 身高控制
- **范围：** 5档身高等级（0.15 - 0.35 m）
- **默认：** 第3档（0.25 m）
- **实时调节：** 拖动滑块即时生效

#### 转向速度控制（手柄专用）
- **范围：** 0.3 - 2.0 rad/s
- **默认：** 1.0 rad/s
- **用途：** 控制手柄旋转的敏感度

#### 摇杆死区控制（手柄专用）
- **范围：** 0.0 - 0.3
- **默认：** 0.1
- **用途：** 避免摇杆漂移，提高控制精度

### 4. ⌨️ 键盘控制区域

**功能：** 键盘控制说明和管理

**控制键位说明：**
- **WASD / 方向键：** 前后左右移动
- **QE：** 左右旋转
- **ZX：** 身高调节（升高/降低）
- **+- (= -)：** 速度调节（加速/减速）
- **空格：** 紧急停止
- **R：** 重置姿态

**特点：**
- **即按即走：** 按下按键立即移动，松开立即停止
- **组合操作：** 支持同时按下多个键进行复合动作
- **全局监听：** 即使焦点不在窗口上也能响应（需启动键盘监听）

### 5. 🎮 手柄控制区域

**功能：** 手柄控制说明

#### 摇杆控制
- **左摇杆：** 控制前后左右移动
  - 前后推拉：前进/后退
  - 左右推拉：左移/右移
- **右摇杆：** 控制左右旋转
  - 左右推拉：左转/右转

#### 按钮控制
- **Y按钮：** 升高身体
- **A按钮：** 降低身体
- **B按钮：** 紧急停止
- **X按钮：** 重置姿态
- **START按钮：** 停止控制

**支持的手柄：**
- Xbox 360/One/Series 手柄
- PlayStation 3/4/5 手柄
- 其他标准游戏手柄

### 6. 🖱️ 按钮控制区域

**功能：** 鼠标点击控制

**按钮布局：**
```
[左转] [前进] [右转]
[左移] [后退] [右移]
```

**使用方法：**
- **鼠标按下：** 开始执行对应动作
- **鼠标释放：** 停止动作
- **组合操作：** 可同时按下多个按钮

### 7. 📊 状态监控与控制区域

#### 控制按钮行
- **开始控制：** 启动当前选择的控制模式
- **停止控制：** 停止所有控制，机器狗静止
- **紧急停止：** 立即停止所有运动
- **重置姿态：** 将机器狗恢复到标准姿态
- **清空日志：** 清除状态显示区的所有日志

#### 状态显示文本框
**实时显示内容：**
- 控制模式
- 当前动作（前进、后退、左移等）
- 速度参数（vx, vy, wz）
- 身高信息
- 速度等级
- 手柄连接状态
- 系统日志和错误信息

**特点：**
- **实时更新：** 每秒更新一次状态信息
- **日志记录：** 记录所有操作和状态变化
- **滚动显示：** 自动保持最新100行日志
- **时间戳：** 每条记录都有精确的时间标记

## 🎯 使用工作流程

### 基本操作流程

1. **启动程序**
   ```bash
   python unified_control.py
   ```

2. **连接机器狗**
   - 输入机器狗IP地址
   - 点击"连接"按钮
   - 等待连接成功（指示器变绿）

3. **选择控制模式**
   - 选择适合的控制模式（键盘/手柄/GUI按钮）
   - 如选择键盘模式，启动键盘监听
   - 如选择手柄模式，确保手柄已连接

4. **调节参数**
   - 根据需要调节速度等级
   - 调节机器狗身高
   - 手柄模式下可调节转向速度和死区

5. **开始控制**
   - 点击"开始控制"按钮
   - 使用选定的方式控制机器狗
   - 观察状态显示区的实时反馈

6. **结束控制**
   - 点击"停止控制"或"紧急停止"
   - 程序自动重置机器狗姿态
   - 断开连接（可选）

### 高级操作技巧

#### 1. 多模式切换
- 可在运行时切换控制模式
- 切换前建议先停止当前控制
- 不同模式的参数设置独立保存

#### 2. 参数实时调节
- 所有参数滑块支持实时调节
- 调节后立即生效，无需重启控制
- 可在控制过程中动态调整

#### 3. 组合操作
- 键盘模式：同时按下WASD进行对角线移动
- 手柄模式：同时操作两个摇杆进行复合动作
- GUI按钮：同时按下多个按钮进行组合动作

#### 4. 安全操作
- 随时可用紧急停止功能
- 程序异常退出时自动重置机器狗
- 连接断开时自动停止所有动作

## 🛠️ 故障排除

### 连接问题

**问题：** 无法连接到机器狗
**解决方案：**
1. 检查机器狗是否开机
2. 确认IP地址是否正确
3. 检查网络连接（ping测试）
4. 确认机器狗和电脑在同一网络

**问题：** 连接成功但无法控制
**解决方案：**
1. 检查机器狗是否处于可控制状态
2. 尝试重置机器狗姿态
3. 重新连接机器狗

### 键盘控制问题

**问题：** 键盘控制无响应
**解决方案：**
1. 确认键盘监听已启动（绿色指示器）
2. 检查是否选择了键盘控制模式
3. 确认程序窗口获得焦点（点击窗口）
4. 重启键盘监听

**问题：** 按键粘滞或不准确
**解决方案：**
1. 检查键盘硬件是否正常
2. 关闭其他可能冲突的程序
3. 重启键盘监听

### 手柄控制问题

**问题：** 检测不到手柄
**解决方案：**
1. 确认手柄已正确连接
2. 检查手柄驱动程序
3. 点击"刷新手柄"按钮
4. 尝试重新插拔手柄

**问题：** 手柄响应不准确
**解决方案：**
1. 调节摇杆死区设置
2. 检查手柄校准
3. 调节转向速度参数

**问题：** 按钮功能异常
**解决方案：**
1. 确认按钮映射是否正确
2. 检查手柄是否为标准布局
3. 尝试使用其他手柄

### 性能问题

**问题：** 界面卡顿或响应慢
**解决方案：**
1. 关闭不必要的后台程序
2. 检查网络延迟
3. 降低状态更新频率

**问题：** 控制延迟
**解决方案：**
1. 检查网络连接质量
2. 确认机器狗状态正常
3. 减少同时运行的程序

## 📝 技术参数

### 系统要求
- **操作系统：** Windows 10/11, macOS 10.14+, Linux
- **Python版本：** 3.7+
- **内存：** 最低512MB，推荐1GB+
- **网络：** WiFi或有线网络连接

### 控制精度
- **更新频率：** 20Hz (每秒20次)
- **响应延迟：** < 50ms（本地），< 100ms（网络）
- **速度精度：** 0.01 m/s
- **角度精度：** 0.01 rad/s

### 支持的设备
- **键盘：** 所有标准键盘
- **手柄：** Xbox、PlayStation、通用游戏手柄
- **鼠标：** 用于GUI按钮控制

## 🔧 高级配置

### 自定义参数

可以通过修改代码中的以下参数来自定义控制体验：

```python
# 速度等级 (m/s)
self.speed_levels = [0.2, 0.5, 0.8, 1.2, 1.5, 2.0]

# 身高等级 (m)  
self.height_levels = [0.15, 0.20, 0.25, 0.30, 0.35]

# 最大转向速度 (rad/s)
self.max_turn_speed = 1.0

# 默认死区
self.deadzone = 0.1
```

### 按键映射自定义

可以修改键盘控制的按键映射：

```python
self.movement_keys = {
    'w': {'vx': 1.0, 'vy': 0.0, 'wz': 0.0, 'name': '前进'},
    's': {'vx': -1.0, 'vy': 0.0, 'wz': 0.0, 'name': '后退'},
    # ... 其他映射
}
```
